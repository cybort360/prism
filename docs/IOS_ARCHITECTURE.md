# Prism iOS Architecture

Native Swift + SwiftUI. Single app target generated by XcodeGen (`ios/project.yml`). No storyboards
beyond the generated launch screen; all UI is SwiftUI.

## Layers

```
PrismApp (@main)                 registers fonts, boots AppModel
 └─ RootView                     isBooting → Onboarding → MainShell
     ├─ OnboardingFlow           story → Mera account → identity → reachability → PIN → Face ID
     └─ MainShell                tab dock (Home / People / Activity / Profile) + sheets
```

| Area | Files |
|---|---|
| App shell / navigation | `App/PrismApp.swift`, `App/AppModel.swift` |
| Design system | `DesignSystem/PrismTheme.swift`, `PrismComponents.swift`, `PrismFontRegistrar.swift` |
| Onboarding | `Features/Onboarding/OnboardingFlow.swift` |
| Feature screens | `Features/{Home,People,Activity,Profile,Send,Request,Receive,Claims,AddMoney,Receipts,Common}` |
| Networking | `Core/Networking/APIClient.swift`, `Services/PrismAPI.swift` |
| Payments | `Services/PaymentCoordinator.swift` |
| Security | `Core/Security/{PINService,BiometricService,KeychainStore}.swift` |
| Contacts | `Core/Contacts/ContactService.swift` |
| Mera bridge | `ios/MeraBridge/*` (see MERA_INTEGRATION.md) |

## Design system

- Cool off-white canvas (`#F7F9F8`), near-black ink (`#0E1312`), restrained jade / mint-teal accent
  (`mint #64C9B3`, `mintDeep #0C574C`), hairline separators (`#E3EAE7`), near-zero shadows.
- Large numeric hierarchy via `AmountText` (F5.6 display face, monospaced digits).
- `PrismTheme.display(_:)` uses **F5.6** when the licensed binary is present under
  `Resources/Fonts/` (registered by `PrismFontRegistrar`), else a high-quality system-rounded
  fallback. The font binary is never committed.
- Body/buttons/metadata use the native SF sans-serif.
- Dollars only. No Naira, no crypto styling, no token portfolio, no network selector, and no
  blockchain terminology in the normal UX. The only address shown anywhere is the user's own
  deposit address on the Add-money screen (unavoidable for receiving funds).

## Navigation

`MainShell` renders one of four tabs and a compact icon-only bottom dock (`PrismTabBar`). Primary
actions live inside Home: **Send, Request, Scan, Add money**. Modal flows are SwiftUI sheets /
`fullScreenCover` driven by `AppModel` presentation state.

## Data flow

`SwiftUI View → PrismAPI (typed request) → APIClient (URLSession, bearer session, Idempotency-Key)
→ Prism backend`. `AppModel` (@MainActor ObservableObject) holds the session-derived identity and
presentation state. Money state is never trusted from the app — balances and payment completion come
from the backend, which treats Monad/AUSD as canonical.

## Payment flow (envelope)

`PaymentCoordinator` runs: **prepare → local approval (PIN / Face ID) → Mera signs the Prism
PaymentEnvelope + the AUSD authorization → submit → poll status**. "Submitted" is never shown as
success; the terminal state comes from a reconciled receipt. See MERA_INTEGRATION.md for the
signing detail.

## Accessibility & responsiveness

- Layouts use Spacers + `minimumScaleFactor` so screens work from iPhone SE to Pro Max.
- Safe areas respected (`prismScreen()`), keyboard-avoidant text entry, VoiceOver labels on icons
  and story pages, Dynamic Type on body text, and legible contrast in both light and dark.

## Build

```bash
cd ios && xcodegen generate
xcodebuild -project Prism.xcodeproj -scheme Prism -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```
